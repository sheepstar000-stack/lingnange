# 灵楠阁小红书内容生成系统 - 使用指南

## 一、系统概述

本系统包含 **5个自动化工作流**，实现从飞书表格读取数据 → AI生成内容 → 写回飞书表格的完整流程。

### 各表格需要准备的内容

**数据要求**：至少填充未来2周的热点事件

---

#### 2️⃣ 产品素材表（必须提前填充）

**用途**：为内容生成提供产品信息和卖点

**必填字段**：
| 字段名 | 说明 | 示例 |
|-------|------|------|
| 产品名称 | 产品名称 | 金丝楠木茶盘 |

**数据要求**：填充所有主要产品信息

---

#### 3️⃣ 选题库（工作流写入）

**用途**：存储生成的选题，管理选题状态

**关键流程**：
- 工作流①自动写入选题
- 人工审核，将状态改为"通过"或"不通过"
- 工作流②只读取"通过"状态的选题

**字段说明**：
| 字段名 | 说明 | 数据来源 |
|-------|------|---------|
| 选题名称 | 选题标题 | 工作流①自动生成 |
| 选题描述 | 详细描述 | 工作流①自动生成 |
| 所属热点 | 关联热点 | 工作流①自动关联 |
| 选题状态 | 待审核/通过/不通过 | 人工修改 |
| 发布账号 | 指定账号 | 人工填写 |

---

#### 4️⃣ 内容成品库（工作流写入）

**用途**：存储生成的内容，管理发布流程

**字段说明**：
| 字段名 | 说明 | 数据来源 |

## 三、工作流运行顺序

### 推荐运行流程

```
┌─────────────────────────────────────────────────────────────┐
│                     周期性运行流程                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  第一步：运行工作流①（热点选题）                              │
│  ├─ 自动读取：热点日历表 + 产品素材表                         │
│  └─ 自动写入：选题库（新增选题）                              │
│                                                             │
│  第二步：人工审核选题                                         │
│  └─ 在选题库中将好的选题状态改为"通过"                        │
│                                                             │
│  第三步：运行工作流②（选题文案）                              │
│  ├─ 自动读取：选题库（通过状态的选题）+ 产品素材表             │
│  └─ 自动写入：内容成品库（生成完整文案）                      │
│                                                             │
│  第四步：运行工作流④（图片建议）                              │
│  ├─ 自动读取：内容成品库（待审核状态的内容）                   │
│  └─ 自动更新：内容成品库的图片建议字段                        │
│                                                             │
│  第五步：人工审核发布                                         │
│  └─ 审核内容、拍摄图片、发布到小红书                          │
│                                                             │
│  第六步：更新数据复盘表                                       │
│  └─ 发布后填写点赞、收藏、评论等数据                          │
│                                                             │
│  第七步：运行工作流⑤（数据复盘）                              │
│  ├─ 自动读取：数据复盘表                                     │
│  └─ 自动写入：选题库（新选题建议）                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 按需运行的工作流

**工作流③（客户故事）**：当有客户愿意分享故事时运行
- 手动输入客户信息
- 自动生成客户故事文案
- 写入内容成品库

## 五、运行检查清单

### 首次使用前检查

- [ ] 热点日历表已填充未来2周热点
- [ ] 产品素材表已填充所有产品信息
- [ ] 选题库、内容成品库、数据复盘表已创建

### 每周运行检查

- [ ] 热点日历表是否需要更新新热点
- [ ] 数据复盘表是否更新了发布数据
- [ ] 选题库"通过"状态的选题是否都已处理

### 工作流运行顺序

```
周一：运行工作流① → 生成选题
周二：审核选题 → 运行工作流② → 生成文案
周三：运行工作流④ → 生成图片建议
周四-周五：拍摄、审核、发布
周末：更新数据复盘表
周一：运行工作流⑤ → 数据复盘
```

## 六、常见问题

### Q1: 工作流①运行后选题库没有新增？
- 检查热点日历表是否有数据
- 检查产品素材表是否有数据
- 检查 app_token 和 table_id 是否正确

### Q2: 工作流②运行后没有生成文案？
- 检查选题库是否有状态为"通过"的选题
- 选题状态必须完全匹配"通过"二字

### Q3: 工作流④没有更新图片建议？
- 检查内容成品库是否有审核状态为"待审核"的内容

### Q4: 工作流⑤分析结果不准确？
- 确保数据复盘表有足够的数据记录
- 数据复盘表至少需要5条以上记录

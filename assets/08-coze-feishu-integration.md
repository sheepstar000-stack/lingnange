## 工作流①：热点选题生成器

### 数据流向

```
热点日历库 ──读取──┐
                   ├──→ 扣子① 大模型 ──→ 选题库
产品素材库 ──读取──┘                    （新增记录）
```

### 读取配置

**节点 1：读取热点日历库**

| 配置项 | 值 |
|--------|-----|
| 插件 | 飞书多维表格 → 查找记录 |
| table_id | `tbl_热点日历库` |
| 筛选条件 | 状态 = "待准备" |
| 排序 | 热点日期 升序 |
| 取几条 | 5 |

**字段映射（热点日历库 → 扣子变量）：**

| 飞书字段 | 扣子变量 |
|----------|----------|
| 热点名称 | `{{hot_topic_name}}` |
| 热点日期 | `{{hot_topic_date}}` |
| 适合账号 | `{{account}}` |
| 推荐内容类型 | —（参考用，不传给提示词） |
| 关联产品（关联字段） | → 跳去产品素材库查 |

**节点 2：读取产品素材库**（根据热点关联的产品查）

| 配置项 | 值 |
|--------|-----|
| 插件 | 飞书多维表格 → 查找记录 |
| table_id | `tbl_产品素材库` |
| 筛选条件 | 产品状态 = "可发布" |
| 取几条 | 10 |

**字段映射（产品素材库 → 扣子变量）：**

| 飞书字段 | 扣子变量 |
|----------|----------|
| 产品名称（多个拼接） | `{{available_products}}` |
| 适合人群（多选拼接） | `{{target_audience}}` |

### 写入配置

**节点 3：写入选题库**

| 配置项 | 值 |
|--------|-----|
| 插件 | 飞书多维表格 → 新增记录 |
| table_id | `tbl_选题库` |

**字段映射（扣子输出 → 选题库字段）：**

工作流提示词输出的是文本块（一 ~ 八），你需要把整个 `result` 写入一个字段，或者手动拆分。

推荐简单做法：扣子输出整个结果写入 **切入角度** 字段（多行文本），人工再从里面挑。后期可以拆分，但先跑通。

| 扣子输出段落 | 写入飞书字段 |
|--------------|-------------|
| 全文 result | 切入角度（多行文本，暂存全部输出） |
| 目标账号（从输入带入） | 目标账号 |
| 关联热点（从读取带入） | 关联热点 |
| 关联产品（从读取带入） | 关联产品 |
| — | 选题状态 = "待审核" |
| — | 创建时间 = 自动 |

### 提示词入参对照

| 提示词占位符 | 来源 |
|--------------|------|
| `{{热点名称}}` | 热点日历库.热点名称 |
| `{{热点日期}}` | 热点日历库.热点日期 |
| `{{账号}}` | 热点日历库.适合账号 |
| `{{可用产品}}` | 产品素材库.产品名称（多条拼接，逗号分隔） |
| `{{目标人群}}` | 产品素材库.适合人群（多条拼接） |
| `{{内容风格}}` | 固定值："新中式、克制、种草但不硬广"（手动设默认值） |

## 工作流②：产品文案生成器

### 数据流向

```
选题库 ──读取──┐
               ├──→ 扣子② 大模型 ──→ 内容成品库
产品素材库 ──读取──┘                 （新增记录）
```

### 读取配置

**节点 1：读取选题库**

| 配置项 | 值 |
|--------|-----|
| 插件 | 飞书多维表格 → 查找记录 |
| table_id | `tbl_选题库` |
| 筛选条件 | 选题状态 = "通过" |
| 取几条 | 1（取最新一条） |

**字段映射（选题库 → 扣子变量）：**

| 飞书字段 | 扣子变量 |
|----------|----------|
| 选题标题 | —（输入给大模型做参考） |
| 目标账号 | `{{publish_account}}` |
| 切入角度 | —（传给大模型，让它理解方向） |

**节点 2：读取产品素材库**（根据选题库关联的产品查）

| 飞书字段 | 扣子变量 |
|----------|----------|
| 产品名称 | `{{product_name}}` |
| 材质说明 | `{{product_material}}` |
| 核心卖点 | `{{product_selling_points}}` |
| 使用场景 | `{{suitable_scenarios}}` |
| 价格区间 | `{{price_range}}` |

### 写入配置

**节点 3：写入内容成品库**

| 飞书字段 | 扣子输出 |
|----------|----------|
| 发布标题 | 人工从输出的 5 个标题里选 |
| 正文 | 输出段落「二、正文」 |
| 内容栏目 | 从选题库.内容栏目 带入 |
| 发布账号 | 从选题库.目标账号 带入 |
| 关联选题 | 从读取带入 |
| 发布标签 | 输出段落「五、标签」 |
| @薯账号 | 输出段落「六」 |
| 评论区引导语 | 输出段落「七」 |
| 内容版本 | 固定 "v1.0" |
| 发布状态 | 固定 "待审核" |

## 工作流③：客户故事生成器

### 数据流向

```
手动输入 ──→ 扣子③ 大模型 ──→ 内容成品库（新增记录）
```

**不接飞书读**。客户故事的信息来源是聊天记录、微信反馈，没有对应的飞书表。输入靠人工填。

### 写入配置

和②一样，写入**内容成品库**：

| 飞书字段 | 值 |
|----------|-----|
| 发布标题 | 人工选 |
| 正文 | 输出正文 |
| 内容栏目 | 固定 "SOP5故事" |
| 发布账号 | 从输入带入 |
| 发布标签 | 输出标签 |
| 评论区引导语 | 输出互动问题 |
| 发布状态 | 固定 "待审核" |

## 工作流④：图片/封面建议器

### 数据流向

```
内容成品库 ──读取──┐
                   ├──→ 扣子④ 大模型 ──→ 内容成品库（更新记录）
产品素材库 ──读取──┘
```

### 读取配置

从**内容成品库**读取一条待配图的内容（筛选：发布状态 = "待审核"）。

| 飞书字段 | 扣子变量 |
|----------|----------|
| 发布标题 | `{{content_theme}}` |
| 关联产品 → 产品素材库.产品名称 | `{{product_name}}` |
| 关联产品 → 产品素材库.产品图片 | `{{image_description}}` |
| 发布账号 | `{{account}}` |

### 写入配置

**更新**内容成品库的那条记录（不是新增）：

| 飞书字段 | 值 |
|----------|-----|
| 封面图 | 按输出建议去做，做完上传 |
| 图片序列 | 按输出建议去拍/做 |
| 风险审核结果 | —（人工审核后再填） |

## 工作流⑤：数据复盘器

### 数据流向

```
数据复盘表 ──读取──→ 扣子⑤ 大模型 ──→ 数据复盘表（更新记录）
                                      选题库（新增下周选题）
```

### 读取配置

每周日跑一次。从**数据复盘表**读取本周所有记录。

| 飞书字段 | 扣子变量 |
|----------|----------|
| 发布账号 | `{{weekly_data}}` 里拼接 |
| 发布标题 | `{{weekly_data}}` 里拼接 |
| 内容栏目 | `{{weekly_data}}` 里拼接 |
| 点赞/收藏/评论/分享/私信/成交 | `{{weekly_data}}` 里拼接 |

**做法**：把本周所有记录拼成一段结构化文本，传入 `{{weekly_data}}`。

### 写入配置

更新**数据复盘表**的"复盘备注"字段，同时在**选题库**新增下周选题建议。

## 对接顺序

```
第 1 步（当前就做）
├── ① 热点选题 ← 读：热点日历库 + 产品素材库
├── ① 热点选题 ← 写：选题库
└── ⏱ 约 1-2 小时

第 2 步（第 1 步完成后）
├── ② 产品文案 ← 读：选题库 + 产品素材库
├── ② 产品文案 ← 写：内容成品库
└── ⏱ 约 1 小时

第 3 步（第 2 步完成后）
├── ③ 客户故事 ← 写：内容成品库（无读飞书）
└── ⏱ 约 30 分钟

第 4 步（第 3 步完成后）
├── ④ 图片建议 ← 读：内容成品库 + 产品素材库
├── ④ 图片建议 ← 写：内容成品库
└── ⏱ 约 1 小时

第 5 步（14 天后，数据积累后）
├── ⑤ 数据复盘 ← 读：数据复盘表
└── ⑤ 数据复盘 ← 写：数据复盘表 + 选题库
```

## 测试标准

每接完一个工作流，用真实数据跑一遍：

```
□ 读取节点能正确查到飞书记录（看日志）
```
